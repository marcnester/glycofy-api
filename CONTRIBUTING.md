# Contributing to Glycofy

Glycofy is proprietary software and is not currently accepting external code,
design, documentation, or other copyrightable contributions. Please do not
submit pull requests containing contributions unless Marc Nester has first
agreed to them in a separate written contributor agreement.

Bug reports and general product suggestions are welcome through the repository's
issue templates. Do not submit confidential information, credentials, personal
data, health information, or undisclosed inventions. Submitting an issue does
not create a confidential, fiduciary, employment, or licensing relationship and
does not obligate Glycofy or its owner to use the submission.

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md),
not through a public issue.
